# Suno v6 prompts: "Late Night with June", the DJ on Smooth Sail FM 96.9

Spoken DJ breaks for the in-game radio station. The host is **June Holloway**, an original character: a low, warm, unhurried voice that feels like a private late-night talk with a close friend. The station is a safe place away from the monster news. Callers share what they're going through, and June listens without judging, offers a little gentle hope, and picks the song that fits. Each break ends by introducing one of the ten station songs, so the game can play the break and then that song.

The monsters are never played for laughs by June. She treats a pod person in the garden with the same tenderness as a broken heart. The humor comes from that contrast.

## How to fill in Suno (Advanced, v6)

**Styles (same for all):**
```
Spoken word only, no singing. A late-night 1980s FM radio DJ talking softly into a close microphone: a low, warm, gentle female speaking voice, slow and intimate, like a private conversation with a close friend. Quiet bed of soft Rhodes electric piano and a warm synth pad underneath, slow 66 BPM, no drums. Soothing, hopeful, cozy.
```

**Exclude styles (same for all):**
```
singing, sung vocals, melody vocals, choir, rap, drums, beat, auto-tune, EDM, rock, upbeat, shouting
```

### Getting Suno to talk instead of sing

- Every paragraph starts with `[Spoken Word]`. Keep that tag; it is what stops the singing.
- The lines are deliberately written as plain sentences that don't rhyme. Rhymes push Suno into singing, so don't add any.
- If a take still sings, generate again. Two or three tries is normal. You can also use **Replace Section** on only the part that sang.
- Suno does one voice well, so June tells each caller's story herself ("Brenda called tonight and told me…"). That keeps it to one convincing voice.
- If a take runs past the `[End]` tag with extra music, trim it in Suno's editor or tell me and I'll cut it.

Download each as MP3 and name it with the file name shown (for example `dj-01-sign-on.mp3`). Send them to me and I'll put them on the station between songs.
